# Highwash — концепт для портфолио

Демонстрационный сайт клининга и высотных работ на Next.js. Логотип и основная визуальная концепция сохранены. Контакты вымышлены; данные реального клиента удалены.

## Разработка

- npm run dev — локальный предпросмотр.
- npm run build — статическая сборка в out/.
- npm start — просмотр сборки.

## Содержание

Каталог содержит 15 услуг: клининг — 3, высотные работы — 2, фасады — 4, остекление — 3, кровля — 3. Для каждой услуги предусмотрена отдельная сгенерированная иллюстрация в public/images/services/.

Формы проверяют данные только в браузере, не отправляют их и не используют локальное хранилище. Контактные заглушки не являются внешними ссылками.

Публикация управляется Sites через .openai/hosting.json. NEXT_PUBLIC_SITE_URL задаёт базовый адрес для метаданных.
